# Estructura de datos
## Apps
### **Facebook**.
Usan estructura de datos de gráfos y árboles. Usan esta para estructurar las relaciones complejas que tienen la bajse de datos.
No usa otra estructura, porque imaginemos un array. Cientos, miles de usuarios la estructura de array no da abasto.

### **Task manager**.
Usa estructura array, "agrupa" las tareas y por medio de decisiones se elige cual se agrega o cual se elimina. No usa por ejemplo grafos o listas hash, debido a la fácil integración y eliminación de tareas.

### **WhatsApp**.
Usa estructura de encolamiento. Usan esta estructura para listar y enviar los mensajes entre grupos o persona a persona. No usa grafos o array, porque los mensajes podrían colisionar entre sí, entregarse o recibirse tarde
